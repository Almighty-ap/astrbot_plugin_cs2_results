## 归档管理准则

1. **归档触发条件**: 仅对已结项的重大事故复盘、跨越多个版本的核心机制重构纪实、重要技术论证进行归档。
2. **拒绝流水账**: 不归档常规聊天记录、未提炼的原始调试日志快照。
3. **权威与引用**: 历史文档记录当时的时空背景与事实；若历史结论已被后续架构覆盖，应在最新 [DECISIONS.md](../DECISIONS.md) 或 [MAP.md](../MAP.md) 中更新，并在本归档中作明确状态注记。
